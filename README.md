# Rückengerechtes Arbeiten

Handy-Seite zur Schulung „Rückengerechtes Arbeiten“ von FaSt.

Die ganze Seite steckt in einer Datei: `index.html`.

## Veröffentlichen mit GitHub Pages

1. Beide Dateien ins Repo hochladen (oberste Ebene, nicht in einen Unterordner).
2. Im Repo: Settings → Pages → „Deploy from a branch“, Branch `main`, Ordner `/ (root)`.
3. Nach ein bis zwei Minuten ist die Seite unter `https://<benutzername>.github.io/<repo-name>/` erreichbar.

Direkt-Links: `#bewohner`, `#core`, `#zuhause`
